Korg Drumlogue 無料プラグイン

CrystalMatrix（フランシスコ・ハビエル・バランドラ・サンチェス） が開発した Korg Drumlogue 向けの無料・実験的プラグイン集です。

Korg Drumlogue SDK プラグイン

本リポジトリに含まれる無料プラグインは、Francisco Javier Balandra Sánchez（CrystalMatrix） によって Korg Drumlogue ハードウェア専用に開発されました。

このリポジトリは、Korg Drumlogue ドラムマシン向けのバーチャルインストゥルメントおよびオーディオエフェクトの開発に特化しています。すべてのプラグインは実機上で徹底した安定性・性能テストを実施しており、実験的な Channel Strip も含まれています。

開発には、無料ソフトウェア Pure Data と PlugData、そして heavy.lib ライブラリを使用しています。heavy.lib は、Pure Data プロジェクトを sdklogue 形式へ変換するために必要なコンポーネントを提供し、Korg Drumlogue との高い互換性を実現します。

Korg Drumlogue 向けのシンセサイザーやオーディオエフェクトの開発に興味がある方は、以下の公式サイトから必要なツールをダウンロードしてください。

1. Pure Data
   https://puredata.info

2. PlugData
   https://plugdata.org/download

3. heavy.lib（Wasted Audio）
   https://github.com/Wasted-Audio/heavylib

本リポジトリのプラグインは、Francisco Javier Balandra Sánchez（CrystalMatrix） によって開発されました。同氏は英国のレコードレーベル EML Recordings および Lazzey Recordings から作品をリリースしているプロデューサー兼エンジニアです。すべてのプラグインは CrystalMatrix Studio において厳格な安定性および性能試験を実施しています。

さらに、本プロジェクトの研究開発の一部は、メキシコ国立自治大学（UNAM） における学術研究活動と連携して行われており、高品質なイコライザーやオーディオプロセッサーの動作を研究・エミュレートすることを目的としています。
