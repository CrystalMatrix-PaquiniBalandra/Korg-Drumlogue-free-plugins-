# Korg-Drumlogue-free-plugins-
Free and experimental plugins for Korg Drumlogue developed by CrystalMatrix aka Francisco Javier Balandra Sánchez .

Free Plugins for Korg Drumlogue: CrystalMatrix, also known as Francisco Javier Balandra Sánchez, has developed an open project focused on creating free and experimental plugins.

This repository explores creative audio development using PureData and PlugData, employing workflows that utilize Wasted Audio's heavylib library. It supports converting PureData files to the sdklogue file format, aiming to provide high-quality instruments. The plugins have undergone rigorous testing to ensure maximum stability.

This repository includes free plugins for Korg Drumlogue, consisting of a series of high-quality emulations of iconic, legendary, and legendary equalizers and channels. These were developed at CrystalMatrix studios and at the National Autonomous University of Mexico (UNAM).
