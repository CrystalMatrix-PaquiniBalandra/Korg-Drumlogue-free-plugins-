Plugins SDK para Korg Drumlogue

Os seguintes plugins gratuitos foram desenvolvidos exclusivamente para o hardware Korg Drumlogue por Francisco Javier Balandra Sánchez (CrystalMatrix).

Este repositório é dedicado ao desenvolvimento de instrumentos virtuais e efeitos de áudio para a drum machine Korg Drumlogue. Todos os plugins foram submetidos a rigorosos testes de estabilidade e desempenho diretamente no hardware, incluindo o desenvolvimento de um Channel Strip experimental.

O desenvolvimento foi realizado utilizando os softwares gratuitos Pure Data e PlugData, juntamente com a biblioteca heavy.lib, que fornece os componentes essenciais para converter projetos para o formato sdklogue, oferecendo excelente compatibilidade com o Korg Drumlogue.

Se você estiver interessado em desenvolver sintetizadores e efeitos de áudio para o Korg Drumlogue, recomendamos baixar as seguintes ferramentas em seus sites oficiais:

1. Pure Data
   https://puredata.info

2. PlugData
   https://plugdata.org/download

3. heavy.lib (Wasted Audio)
   https://github.com/Wasted-Audio/heavylib

Os plugins incluídos neste repositório foram desenvolvidos por Francisco Javier Balandra Sánchez (CrystalMatrix), produtor e engenheiro com lançamentos pelos selos britânicos EML Recordings e Lazzey Recordings. Cada plugin foi submetido a extensivos testes de estabilidade e desempenho no CrystalMatrix Studio.

Além disso, parte da pesquisa e do desenvolvimento deste projeto foi realizada em colaboração com atividades de pesquisa acadêmica na Universidade Nacional Autônoma do México (UNAM), com o objetivo de estudar e emular o comportamento de diversos equalizadores e processadores de áudio de alta qualidade.
