Бесплатные и экспериментальные плагины для Korg Drumlogue, разработанные CrystalMatrix, также известным как Франсиско Хавьер Баландра Санчес.

SDK-плагины для Korg Drumlogue

Следующие бесплатные плагины были разработаны исключительно для аппаратной платформы Korg Drumlogue Франсиско Хавьером Баландра Санчесом (CrystalMatrix).

Этот репозиторий посвящён разработке виртуальных инструментов и аудиоэффектов для драм-машины Korg Drumlogue. Все плагины прошли тщательное тестирование стабильности и производительности непосредственно на устройстве, включая разработку экспериментального Channel Strip.

Разработка выполнена с использованием бесплатных программ Pure Data и PlugData, а также библиотеки heavy.lib, которая предоставляет необходимые компоненты для преобразования проектов в формат sdklogue и обеспечивает высокую совместимость с Korg Drumlogue.

Если вы заинтересованы в разработке синтезаторов и аудиоэффектов для Korg Drumlogue, рекомендуется загрузить следующие бесплатные инструменты с их официальных сайтов:

1. Pure Data
   https://puredata.info

2. PlugData
   https://plugdata.org/download

3. heavy.lib (Wasted Audio)
   https://github.com/Wasted-Audio/heavylib

Плагины, представленные в этом репозитории, разработаны Франсиско Хавьером Баландра Санчесом (CrystalMatrix) — продюсером и инженером, чьи работы выпускались британскими звукозаписывающими лейблами EML Recordings и Lazzey Recordings. Каждый плагин прошёл всесторонние испытания на стабильность и производительность в CrystalMatrix Studio.

Кроме того, часть исследований и разработки этого проекта была выполнена в сотрудничестве с академическими исследовательскими программами Национального автономного университета Мексики (UNAM) с целью изучения и моделирования поведения различных высококачественных эквалайзеров и аудиопроцессоров.
