Korg Drumlogue SDK 插件

以下免费插件由 Francisco Javier Balandra Sánchez（CrystalMatrix） 专为 Korg Drumlogue 硬件平台开发。

本仓库专注于为 Korg Drumlogue 鼓机开发虚拟乐器和音频效果器。所有插件均已在真实硬件上进行了严格的稳定性和性能测试，其中包括一个实验性的 Channel Strip。
